# Часть 1. Подготовка кода и локальная работа



Готовое приложение на языке Go делаю форк проекта golang-helloworld,
обновляю его до современного состояния, пишу тесты и упаковываю в Docker-контейнер
Проверяю, что всё работает на своём компьютере. Фундамент приложения готов 



| Элемент | Что это  |
|---|---|
| `main.go` | Само приложение: веб-сервер, который отвечает «Hello» на запросы. Умеет отдавать метрики (`/metrics`) и отвечать на проверки здоровья (`/healthz`, `/readyz`) |
| `main_test.go` | Автоматические тесты: проверяют, что сервер действительно отвечает правильно |
| `go.mod` / `go.sum` | Список зависимостей и версий языка Go (как package.json у JavaScript) |
| `Dockerfile` | Из исходников собераю готовый образ контейнера |
| `.dockerignore` | Список файлов, которые не нужно копировать в образ (мусор, папки инфраструктуры) |

## Как это работает (по шагам)

1. Приложение слушает порт **8080** на всех сетевых интерфейсах (`:8080`). 
2. Каждый HTTP-запрос проходит через обёртку `instrument()`, которая:
   - пишет строку в лог (`GET / 2.3µs`)
   - увеличивает счётчик метрик Prometheus (понадобится в части мониторинг)
3. Проверки `/healthz` и `/readyz` не проходят через эту обёртку — иначе каждая
   служебная проверка засоряла бы логи и метрики.
4. `Dockerfile` собирает приложение в два этапа (мультистейдж): сначала компиляция
   в образе с Go, потом готовый бинарник копируется в маленький образ Alpine
   (итоговый образ занимает значительно меньше места ~15 МБ если соирать все вместе получу  ~800 МБ).

## Итог этапа

- Работающий код + Dockerfile. Из них в части 2 CI будет собирать образы,
  в части 5 этот образ запустится в Kubernetes.

## Основные команды

```bash
go build ./...        # собрать
go test ./... -v       # прогнать тесты
go run main.go         # запустить локально → http://localhost:8080

docker build -t final-dm-dos35:first .     # собрать образ
docker run -d -p 8080:8080 --name app final-dm-dos35:first   # запустить контейнер
curl http://localhost:8080                  # проверить
```

## Где что лежит

```
main.go            — приложение

Dockerfile         — сборка образа
.dockerignore      — исключения для сборки образа
go.mod / go.sum    — зависимости Go
```
